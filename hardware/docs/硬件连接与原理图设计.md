# CH32L103K8U6 USB→CAN 硬件连接与原理图设计
> 目标：用 **CH32L103K8U6（QFN32，4×4mm）** 做一个 USB(CDC) 转 CAN 的小板，
> CAN 速率 **1 Mbps**，驱动 **DM-J4310-2EC**（达妙 24V 减速电机，10:1 减速比，
> 出厂 CAN 1Mbps / STD 11bit）。
> 配套文件：`USB2CAN_接线图.svg`（接线示意），工程与协议见 `02_固件/`、`04_工程/`。

## 1 设计结论（先看这个）
- USB 全速设备占 **PA11(USBDM) / PA12(USBDP)**，因此 CAN1 **必须重映射**到
  **PB8(CAN1_RX) / PB9(CAN1_TX)**（`AFIO_PCFR1[14:13] CAN1_RM = 10b`，RM 手册 10.3.2.2 表）。
  固件 `can_bsp.c` 直接写寄存器完成，不用库宏 `GPIO_Remap1/2_CAN1`（库实现跨 PCFR1+PCFR2，语义不清）。
- **CH32L103K8U6 无 NRST 引脚**；**pad31=BOOT0 与 PB9 内部合封**：
  - 外部给 PB9 加 **4.7kΩ 下拉**（保证上电从 Flash 启动、BOOT0=0）；
  - PB9 **不耐 5V**，收发器必须选 **3.3V 供电型**（SIT1051T/3、TJA1051T/3、SN65HVD230 等），
    禁止直接接 5V 收发器/5V 逻辑。
- USB 的 D+ 上拉用 **芯片内部 1.5kΩ**（固件 `USBFS_UC_DEV_PU_EN` 已开，见 RM 表 20-2），
  板上**不需要**外置 1.5kΩ 上拉；D−/D+ 直连 MCU，串 22Ω 可选。
- 电机侧 **24V 电源不进本板**：本板只接 CANH/CANL/GND（与电机电源“单点共地”）。
- 板载 3.3V 由 **USB VBUS 5V → LDO** 得到；电机另接 24V 电源。
- 上电顺序：**先插 USB（板上电并枚举 CDC），再给电机 24V**；下电顺序相反。

## 2 引脚分配（QFN32 焊盘号已按 CH32L103DS0 引脚表逐脚核对）
> 本表为“最小 USB→CAN 核心”所需引脚。**整板全 IO 分配（UART1/UART2/4×ADC/
> WS2812/LED/2 舵机/扩展排针）见《扩展功能与全IO分配.md》**，两者不冲突，
> 下表之外的其余 GPIO 均已安排到扩展功能或排针，没有空置。

| 焊盘# | 引脚 | 方向 | 用途 | 外部连接 |
|------|------|------|------|----------|

| 31 | PB9 / BOOT0 | O | CAN1_TX | 收发器 TXD（输入）+ **4.7kΩ 下拉到地** |
| 23 | PA13 | I/O | SWDIO | WCH-Link SWDIO |
| 24 | PA14 | I/O | SWCLK | WCH-Link SWCLK |

## 3 接线表

### 3.1 USB 侧（PC ↔ 板）
| 板端 | 信号 | 去向 |
|------|------|------|
| PA12(pad22) | D+ | USB 座 D+（建议串 22Ω） |
| PA11(pad21) | D− | USB 座 D−（建议串 22Ω） |
| — | VBUS 5V | LDO 输入（串 100mA～500mA 自恢复保险可选） |
| — | GND | USB GND → 系统地 |
- 用 **Micro-B/Type-C 座**均可。若用 **Type-C 插座**且想当“U 盘式设备”插 Type-C 主机，
  需在 **CC1/CC2 各接 5.1kΩ 下拉到地**（或直接用 Type-C 转 Micro-B 线 + Micro-B 座最省事）。
- ESD（可选）：NUP2105L / USBLC6-2 等，放在连接器脚，D±/VBUS/GND。
- 芯片内部 1.5kΩ D+ 上拉由固件开启（USBFS BASE_CTRL `USBFS_UC_DEV_PU_EN`），无需外置。

### 3.2 电源
| 器件 | 值/型号 | 说明 |
|------|---------|------|
| LDO | ME6211C33 / HT7333 / AMS1117-3.3 | 5V→3.3V，≥100mA |
| 输入电容 | 1µF/10µF | VBUS 侧 |
| 输出电容 | 10µF + 100nF | 3.3V 侧，紧靠 MCU |
| MCU VDD 去耦 | 100nF×多 + 1~10µF | 每 VDD 就近 |
| 保险丝(可选) | 自恢复 100~500mA | USB VBUS 入 |

### 3.3 CAN 收发器（3.3V）
| MCU 引脚 | ←→ | 收发器 |
|----------|----|--------|
| PB9 CAN1_TX(pad31) | → | TXD（输入） |
| PB8 CAN1_RX(pad32) | ← | RXD（输出） |
| — | | VCC=3.3V（100nF 就近），GND 共地 |
| — | | S/STB 经 10kΩ 下拉到地（正常模式，勿悬空） |

选型（3.3V、1Mbps、兼容 3.3V I/O）：**SIT1051T/3、TJA1051T/3、SN65HVD230**（或 MCP2562FD）。
SIT1051T/3 与 TJA1051T/3 引脚兼容，性价比高。

### 3.4 总线侧 → DM-J4310-2EC
| 本板 | 信号 | 电机端 |
|------|------|--------|
| 收发器 CANH | CANH | 电机电源 XT30(2+2) **小针（CANH）** |
| 收发器 CANL | CANL | 电机电源 XT30(2+2) **小针（CANL）** |
| 系统 GND | GND | 电机电源 GND（大针） |
- 电机两个 XT30 接口内部并联，可任接一个（也可“桥→电机1→电机2”串联走线）。
- **接线前务必用万用表/原厂线缆确认小针/大针与 CANH/CANL、24V+/GND 的对应**，
  图纸只是文字示意，原厂线缆的线色以实物为准。
- CANH/CANL 用**双绞线**；本板出口建议 22~33Ω 串阻、靠近电机端可加 TVS（如 PESD1CAN）。
- 终端：板上预留 **120Ω + JP1 跳线**。两节点短线（<1~2m）通常合上 JP1 效果最好；
  若电机驱动板内部已带终端电阻或总线较长，按示波器波形调整。

### 3.5 SWD / BOOT
- WCH-Link：3.3V、GND、SWDIO(PA13)、SWCLK(PA14) 四根（**K8U6 没有 NRST 脚**，
  下载器用“断电/复位后连”方式，MounRiver/OpenOCD 的 wch-riscv 配置已支持）。
- BOOT0(PB9/pad31)：4.7kΩ 下拉。BOOT1(PB2/pad16)：4.7~10kΩ 下拉（从用户 Flash 启动）。

### 3.6 LED
- PA15 状态/心跳：串 470Ω~1kΩ → LED → VDD（高有效）。固件 0.5s 翻转，上电即应有。
- PB4 错误：同上接法（可选），固件在 CAN TX 失败/丢帧/坏帧时闪 20ms。
- PB5 已改作 WS2812 数据口，勿再当 LED 用（见《扩展功能与全IO分配.md》）。

## 4 PCB 注意
- QFN32 底部 **Exposed Pad(pad0) 必须接地**，开钢网过孔到地平面，散热+电气。
- 3.3V/GND 铺铜；**去耦电容紧贴 VDD**；D+/D− 走线短、等长、并行走。
- CAN 收发器尽量靠近 XT30/端子；TXD/RXD 到 MCU 走线短。
- USB 座与电机 24V 线远离；本板电源只有 USB 5V。
- 若电机线很长或有感性负载，24V 地与 USB 地“单点共地”（只在电源端用短粗线连一次），
  或用隔离收发器（如 ISO1050 + 隔离电源）进一步隔离，普通桌面测试不必。

## 6 联调顺序（防呆）
1. **不接电机**，插 USB → 电脑出现 `USB 串行设备(COMx)`（CDC 免驱），PA15 心跳 0.5s 闪。
2. 用 `dm_j4310_usbcan.py COMx probe` 或达妙调试助手确认 **ESC_ID / MST_ID / 波特率 1M**。
   （电机默认 1M；若被设成 >1M 会进 CAN FD，普通 CAN 收不到反馈，务必改回 4=1M。）
3. 再接电机 24V，先 `probe/status`（失能状态读寄存器），红灯=失能属正常。
4. `set_mode 2`（位置速度）→ `enable`（绿灯）→ `move 位置 限速`。
5. 首次动轴前请把负载脱开或限速设小，确认方向与单位。
