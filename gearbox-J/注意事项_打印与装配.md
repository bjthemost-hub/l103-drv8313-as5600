## 2. 摆放取向（建议）

| 件 | 怎么摆 | 理由 |
|---|---|---|
| **齿圈** | **立着打**（轴向竖直 = 打印 Z） | 内齿齿面变成竖直壁，层纹沿齿高堆，齿形最准；也不用支撑 |
| **行星轮 ×6**（C / D / E / F / J）**、×8（K / L / M）** | **立着打**（齿轮轴线竖直） | 同上。平放的话齿顶那圈会有台阶 |
| **行星轮**（G / H） | 同上；**两种件分开摆**：`02_planet_s1` 一级 3 个、`03_planet_s2` 二级 3 个（H 是 4 个） | 同上。两级齿数不同，是两种零件 |
| **输入太阳轮** | **轮毂朝下打**（Ø10 轮毂坐在床上，齿朝上） | Ø5 D 孔是竖孔，不用桥；孔口倒角自带过渡。反着打孔顶那 1.10 mm 盲孔盖要过桥（也能打，但不如正着顺） |
| **行星架** | **架盘放平**（盘贴床，销轴朝上/朝下都行；C/D 盘 Ø44，**方案 E 是 Ø33.95 / 方案 F 是 Ø38.95 / 方案 G 是 Ø40.63 / 方案 H 是 Ø38.69 / 方案 J 是 Ø43.39 / 方案 K 是 Ø43.84 / 方案 L 和 M 是 Ø43.96**） | 盘是最大平面，贴床最稳；二级太阳轮是**下沉嵌进盘里的**，不会悬空 |
| 全部件 | 尽量不用支撑 | 齿圈立着打时内齿上方是空的，不需要支撑 |

## 3. 打印参数（建议，未实测）

- **喷嘴/层高**：能换 **0.25 或 0.3 mm 喷嘴**的话齿形会明显好过一整套 0.4 喷嘴
  （C/D 齿顶厚 0.52~0.85 mm，0.4 喷嘴打出来会偏钝）。
- **方案 E（m = 0.70）再加一条硬要求**：E 的三个齿顶厚是 **0.496 / 0.477 / 0.657 mm**，
  齿顶最尖处比 0.4 mm 喷嘴的**口径**还小一点。**用 0.4 喷嘴打 E 会明显圆头/缺料**，
  齿顶一钝就等于把背隙放大。E 建议 **0.25 mm 喷嘴**（层高 0.10~0.12）或光固化；
  非要用 0.4 喷嘴，就先把**一组行星轮 + 太阳轮**单独打出来看齿顶，能接受再打全套。
  （"齿顶厚要 ≥ 喷嘴口径"是推论，不是我在你的机器上实测的结论。）
- **方案 F（m = 0.80）没有这条硬要求**：三个齿顶厚 **0.571 / 0.550 / 0.755 mm**，比 0.4 mm 口径宽，
  0.4 喷嘴能印出方角（层高 0.12~0.16 mm、速度 25~35 mm/s）。**这是四版里齿顶第二厚的（仅次于 C），
  先打它最稳。**
- **方案 G / H 与 F 同档，不用特殊处理**：G 用的就是 F 那个 m = 0.80（三个齿顶最薄 0.485~0.559 mm），
  H 是 m = 0.85（最薄 0.507~0.597 mm），都比 0.4 mm 喷嘴口径宽 —— 打印参数照 F 那套直接用（见上一条），
  **不需要 E 那种"换小喷嘴"的特殊要求**。外形上 G 的齿圈 Ø51.55（比 F 大 1.60 mm）、H 的 Ø49.67（比 F 小 0.28 mm），
  一般热床都放得下。
- **方案 J（m = 0.95）比 F 还宽裕**：三个齿顶厚 **0.531 / 0.630 / 0.956 mm**，最薄处只比 F 的 0.550 薄 0.019、
  比 C 的 0.524 还略厚 —— 0.4 喷嘴能印方角，**打印参数照 F 那一套直接用**。外形上齿圈 **Ø54.81**（比 F 大 4.86 mm），
  **热床和端盖按 Ø54.81 留**（离 Ø56 上限还剩 1.19 mm）。
- **方案 K（m = 0.95，16 : 1，每级 4 个行星轮）比 J 还宽裕**：三个齿顶厚 **0.694 / 0.694 / 0.963 mm** ——
  **八版里最厚的一版**，0.4 喷嘴非常轻松，打印参数照 F / J 那一套直接用。外形上齿圈 **Ø55.21**
  （比 J 大 0.40 mm，**离 Ø56 上限只剩 0.79 mm**），**热床和端盖按 Ø55.21 留**；行星架盘 Ø43.84。
- **方案 L（m = 0.95，25 : 1，每级 4 个行星轮）和 K 一样宽裕**：三个齿顶厚 **0.660 / 0.806 / 1.007 mm**，
  0.4 喷嘴都没问题，打印参数照 F / J / K 那一套直接用。外形上齿圈 **Ø55.21（和 K 完全相同）**、行星架盘 Ø43.96。
  **但 L 的齿数是 12-18-48（K 是 16-16-48）—— 别把两版的齿圈/行星轮混着打**，那会啮合不上。
- **方案 M（m = 0.95，25 : 1，齿厚 4.00）与 L 同档，打印参数照 L 那一套直接用**：三个齿顶厚
  **0.660 / 0.806 / 1.007 mm**（与 L 逐格相同 —— 加厚只动轴向、不动端面齿形），齿圈 **Ø55.21**（与 K / L 相同）。
  **不一样的是高度**：齿圈 **13.60 mm 高**（L 是 10.70），**热床摆放与端盖让位腔都按 13.60 的高度留**；
  行星轮 4.00 厚（L 3.10）。**别把 M 和 L 的齿圈 / 行星轮混着打。**
- **壁数**：3~4 圈（齿本身就是薄壁件，靠壁数保证强度）。
- **填充**：行星架盘/齿圈 20~40% 就够（受力主要走齿和壁）。
- **材料**：PLA 最省事、尺寸最稳；PETG 更韧但更容易拉丝/偏大。别用特别软的（齿会磨）。
- **缩放**：先按 100% 打。真有系统性偏差，用切片器的 XY 补偿统一修（见第 5 节）。

## 4. 装配顺序

装配前把行星轮内孔、齿圈内齿的毛刺清干净（C / D / E / F 是 6 个行星轮；**G 是 6 个、H 是 7 个；J 是 6 个、K / L / M 是 8 个**）。

> 下面按 C / D / E / F 的文件名写（`02_planet_gear`、`03_input_sun`、`04_carrier1_sun2`、`05_output_carrier`）。
> **G / H 的对应关系**：`02_planet_s1`（一级行星轮）+ `03_planet_s2`（二级行星轮）、`04_input_sun`、
> `05_carrier1_sun2`、`06_output_carrier`。步骤完全一样，只是名字和件数不同。
> **J 和 K / L / M 用的就是上面 C ~ F 那一套名字**（行星轮都是 `02_planet_gear`，J 是 6 个、K / L / M 是 8 个），一个字都不用换。

1. **压轴承**：每个行星轮各压一个 **Ø7 外径**轴承（C / D / E / F 是 6 个，**G 是 6 个、H 是 7 个、J 是 6 个、K / L / M 是 8 个**）。
   厚 3 mm 的话正好嵌在 3.10 深的内孔里（**方案 M 的内孔深 4.00** —— 齿厚加到了 4.00）。
   压不进去先轻微铰一下，或用热风枪把行星轮加热到 60~70 °C 再压（PLA 别过热，会软塌）。
2. **一级总成**：3 个行星轮套到 `04_carrier1_sun2` 的 **3 根销轴**上（**方案 K / L / M 是 4 个行星轮 / 4 根销轴**；销轴朝 −Z 那一侧）。
3. `03_input_sun` 从**下方**插进这 3 个行星轮中间，让太阳轮齿与行星轮啮合。
4. **二级总成**：另外 3 个行星轮（**H / K / L / M 是 4 个**）套到输出侧行星架的销轴上（销轴同样朝 −Z）。
   输出侧行星架：C / D / E / F **和 J** 是 `05_output_carrier`（3 根销轴）；**K / L / M 也是 `05_output_carrier`，但是 4 根销轴**；
   **G 是 `06_output_carrier`（3 根）、H 是 `06_output_carrier`（4 根）**。
5. **齿圈立起来**（下端面朝下，即 Z = −0.30 那面在下面；**方案 M 是 Z = −1.00 那面在下面**）。
6. **一级总成**从齿圈上方放进去 —— 一级行星轮的齿进入齿圈内齿 **Z = −0.30…3.40 这一段**（连续内齿版这里是同一条齿贯通的一截；分段版是下段内齿带）。
   **方案 M 的一级行星轮在 Z = 0.00…4.00**，而 M 的齿圈是 **−1.00…12.60 一整条内齿**（M 只有连续内齿这一种形态）。
7. **二级总成**从齿圈上方放入：一边下一边轻转，让一级行星架顶上那颗**二级太阳轮**插进全部二级行星轮之间
   （C~G 是 3 个、**H 是 4 个、J 是 3 个、K / L / M 是 4 个**；一级行星架 C / D / E / F **和 J / K / L / M** 是 `04_carrier1_sun2`、
   **G / H 是 `05_carrier1_sun2`**），
   二级行星轮的齿进入齿圈内齿 **Z = 6.40…10.10 这一段**（连续内齿版同样是同一条齿；分段版是上段内齿带）。
   **方案 M 的二级行星轮在 Z = 7.60…11.60**（M 的齿圈是 −1.00…12.60 一整条内齿）。
8. 盖上你自画的**输入端盖**和**输出端盖**，把整套夹住（轴向靠两个端盖定死，齿圈被压住不转）。

**相位不用你找**：齿圈的方向已经烘在零件里（按 STEP 方位装入，别把齿圈反过来）；
**C ~ K 每一级的行星轮相位本来就完全相同**，插进去自然对。
**只有 L 和 M 例外**（这两版齿数完全相同）：齿数组合是 (Zs + Zp) = 12 + 18 = 30，30 % 4 = 2 ≠ 0，
所以每级 4 个行星轮**分两种摆放相位**（10.0000° × 2 个 / 0.0000° × 2 个，相差半个齿距 = 10°）。
**零件还是同一个件** —— 每个位置只有一种角度能落到位（齿槽对不上就换下一个齿槽，或把轮转过半个齿距），
4 个位置对着齿槽轻轻一转就都到位，**不需要你自己算角度**。K（16 + 16 = 32，32 % 4 = 0）没有这件事。

**G / H 另外两句**：

1. **两级行星轮不能混**：G 的一级是 `02_planet_s1`（21 齿）、二级是 `03_planet_s2`（18 齿）；
   H 是 18 齿 / 16 齿。**装反了啮合不上**（齿数不对），按齿数或按文件名分。
2. **销轴根数变了一种**：`05_carrier1_sun2` 上是一级 **3 根**销轴；`06_output_carrier` 上 **G 是 3 根、H 是 4 根**。
   方位同样烘在零件里，直接套上去就行（4 个位置只有一种装法）。

**K 另外两句**：

1. **两级行星轮是同一个件**（16 齿，8 个完全一样），两级之间装混了也啮合得上 —— 没有 G / H 那个出错点；
   两个行星架上各 **4 根销轴**，4 个行星轮 **90° 均布**，方位同样烘在零件里。
2. **别把 K 和 J 的齿圈弄混**：两版都是 48 齿、外径只差 0.40 mm（J Ø54.811 / K Ø55.210），
   但内齿顶不一样（J Ø44.640 / K Ø45.091），**行星轮也不通用**（J 是 12-18-48，K 是 16-16-48）。
   分不清就量内齿顶；或者量外径（差 0.40 mm，卡尺分得出来）。

**L 另外两句**：

1. **L 和 J 的齿数完全一样（12-18-48）**，只是每级 4 个行星轮、齿圈 Ø55.210（J 是 Ø54.811）。
   但 **J 的行星轮和 L 的行星轮不是同一个零件**（J 齿顶 Ø18.934 / L Ø18.768，齿根 J Ø14.668 / L Ø14.867，
   内孔都是 Ø7）—— 混着打会啮合偏紧，**别混**。
2. **L 和 K 的齿圈外径完全相同（都是 Ø55.210）、都是 48 齿**，但齿数组合不同（K 16-16-48 / L 12-18-48，
   内齿顶 K Ø45.091 / L Ø45.214）。**齿圈和行星轮都不通用** —— 分不清就数行星轮齿数（16 是 K、18 是 L）
   或量内齿顶（差 0.123 mm，卡尺够量）。

**M 另外两句**：

1. **M 和 L 的齿数、模数、变位、齿顶高系数、内孔、销轴全部都一样**，**只有齿厚与 Z 分层不同**
   （M 齿厚 4.00、齿圈 13.60 高、整机 28.90 高；L 是 3.10 / 10.70 / 27.10）。
   所以 **M 的齿圈 / 行星轮 / 输入太阳轮三件与 L 都不通用** —— 混着打要么啮合偏紧（齿厚差 0.90），
   要么轴向装不进去。分不清就量齿宽（4.00 是 M）或量齿圈高度（13.60 是 M）。
2. **M 与 L 一样，每级 4 个行星轮分两种摆放相位**（见上面相位那段），4 个轮本身仍是同一个件。

**Ø5 D 孔先试装，别硬砸**：`03_input_sun`（**J / K / L / M 也是这个名字**；G / H 是 `04_input_sun`）的 Ø5 D 盲孔是按**名义尺寸**做的（D 面到轴心 2.00 = 对面距 4.50）。
FDM 打出来的孔通常偏小，先拿你的 5 mm D 轴（或一截 Ø5 圆棒）试插：

- 插不进 → 用 Ø5 铰刀/钻头轻修孔的圆面，**再**用锉刀修 D 平面（别一上来就锉 D 面，会把配合面锉松）；
- 太松（能晃）→ 涂一点点厌氧胶/瞬干胶固定，或者告诉我把 D 面从 2.00 收到 1.90 重出。
- 轴插到底要有 **8.00 mm** 的插入量（**方案 M 是 8.90 mm** —— 齿厚 3.10 → 4.00 之后孔跟着深了）；
  孔顶还剩 1.10 mm 材料，**别用长轴硬顶**（会顶穿那 1.10 mm 的盲孔盖）。

## 5. 孔的公差怎么修（Ø7 轴承孔）

设计值内孔 **Ø7.00**（配 Ø7 外径轴承）。FDM 打出来的孔通常**偏小**
（偏多少取决于你的机器/材料/流量，**我没有你这个组合的数据**），所以：

- **优先做法**：在切片器里只对**行星轮那几种件**加**孔补偿 / XY 尺寸补偿**（Orca/PrusaSlicer 里叫
  "XY 尺寸补偿" 或 "孔洞补偿"，一般从 −0.05 ~ −0.15 mm 起试），比改模型方便。
  要补偿的件：C / D / E / F **和 J / K / L / M** 是 `02_planet_gear`；**G / H 是 `02_planet_s1` 和 `03_planet_s2`（两个都要）**。
  （**J / K / L / M 只用补偿一种件** —— 行星轮都是 `02_planet_gear`，J 是 6 个、K / L / M 是 8 个。）
- 也可以把该件 XY 缩一点打几个试件，找到"压得进又不太松"的量。
- 真要改模型：`work\part_layout.py` 的 `LAYOUT` 里 `planet_bore` 改一个数重出即可。

**别把孔打大了**：孔松了行星轮会在销轴上晃，等于直接吃掉齿侧间隙。

## 6. 装好之后怎么量背隙（建议一定量一次）

设计值只是理论值（**输出侧**：C 16.8′ / D 15.9′ / E 21.6′ / F 18.9′ / **G 18.2′ / H 19.2′ / J 17.4′ / K 17.0′ / L 17.4′ / M 17.4′ / N 约 8.7′（外推）**；
输入侧是它的 4.0~4.7 倍：C 79.4′ = 1.32°、D 71.7′ = 1.20°、E 102.0′ = 1.70°、F 89.3′ = 1.49°、
G 73.0′ = 1.22°、H 76.9′ = 1.28°、**J 86.9′ = 1.45°、K 67.9′ = 1.13°、L 87.0′ = 1.45°、M 86.98′ = 1.45°、N 约 43.5′ = 0.72°（外推）** —— 分度圆越小，同一个打印误差折算成的角度越大），
**打印后一定更大**。
**你在下面第 2~4 步量到的是「输出侧」那一列**（早先 C~F 的报表把输入侧的数填在了「输出」名下，差 4.5~4.7 倍，2026-09-29 已改）。测法：

1. 输入端（太阳轮里的 5 mm D 轴）**夹死不动**，齿圈也固定（本来就被端盖压住）。
2. 在输出凸台（Ø8）上装一个摆臂，比如装一根 **50 mm 长**的杆（回转中心到测量点 50 mm）。
3. 杆末端架一个**百分表**。
4. 一只手把输出杆往一个方向使劲，读表；再往反方向使劲，读表。两个读数之差 = 端点总位移。
5. 换算：**1 mm 端点位移 = 1.146° = 68.75′**（= atan(1/50)，因为测量半径是 50 mm）。
   想直接读角度就把杆加长（100 mm 杆 → 1 mm = 0.573°）。

实测出来后调 `thin` 重出（thin 减半，背隙基本减半 —— 关系是**线性**的，这就是它的定义）就能把背隙往你要的方向收。
分方案的表：`work\backlash_table_int.txt`（**C~M 十套一表，两级分开列**，2026-10-16 重出、加了 M；**M 与 L 逐格相同**）；
**这个表里没有 N** —— thin 0.015 低于它那套多边形模型的解析度，算出来会是假值（0），要可信就得提高 n_flank 重跑（本次没做），
所以 N 的背隙只能用线性关系外推，**真值请以您手上的实物为准**；
文字版在 `图纸与交付说明.md` 第 12.4 节（E / F）、第 13 节（G / H）、第 14 节（J）、第 15 节（K）、第 16 节（L）、第 17 节（M）与第 18 节（N）。

## 7. 已知的工艺/强度注意点（都是我在建模时踩过或特意处理的）

1. **二级太阳轮不是细颈**：一级行星架（C / D / E / F 是 `04_carrier1_sun2`，**G / H 是 `05_carrier1_sun2`**）
   顶上那颗二级太阳轮是**下沉 1.20 mm 嵌进架盘里**的（实体合并）。
   之前一版它是靠 Ø5×0.30 的细颈连在盘上 —— 3D 打印件扭起来会先断那条颈，所以改掉了。
   你拿到件后应该看到齿根直接长在盘面上，这是对的。
2. **销轴只是穿在行星轮的 Ø7 内孔里**（径向留 **1.70 mm**；**方案 F / G / H / J / K / L / M 是 Ø4.06，留 1.47 mm**）；真正承力/定心靠**你压进去的 Ø7 轴承**。
   所以轴承一定要压到位、别偏心。详见 `图纸与交付说明.md` 第 8 节（Ø7 轴承内孔要先量）。
3. **齿圈内齿有两种版本，都正常**：
   - `outputs\ring_cont\...`（连续内齿，**推荐**）：内齿从 −0.30 到 10.40 **一通到底**，没有任何让位孔/台阶 —— 这是能一次加工出来的形式。
     （**方案 M 是 −1.00 到 12.60** —— 齿圈比 L 长 2.90，两端各多留 1.00。）
   - `outputs\...`（分段内齿，原版）：下段 −0.30…3.40、上段 6.40…10.10，中间 3.40…6.40 是 Ø49.4/Ø49.9 让位孔。
   连续内齿版里，一级行星架盘与内齿顶之间只有 **0.61 mm（C，Ø44 / Ø45.23）、0.85 mm（D，Ø44 / Ø45.70）、0.61 mm（E，Ø33.95 / Ø35.178）、0.63 mm（F，Ø38.95 / Ø40.204）、0.62 mm（G，Ø40.63 / Ø41.880）、0.63 mm（H，Ø38.69 / Ø39.941）、0.62 mm（J，Ø43.39 / Ø44.640）、0.63 mm（K，Ø43.84 / Ø45.091）、0.63 mm（L，Ø43.96 / Ø45.214）、**0.63 mm（M，Ø43.96 / Ø45.214）** 径向间隙（设计值）；
   如果打印后行星架盘外径涨了、或齿圈缩了，这个间隙会变小。**打之前量一下行星架盘外径**，
   偏大就在切片器里把两个行星架单独 XY 缩一点（C / D / E / F **和 J / K / L / M** 是 `04`/`05`，**G / H 是 `05`/`06`**）。
4. **行星架盘的销轴是"平接"在盘面上的**（同一材料，打印时层纹连续）。受力方向是剪切，
   如果长期大扭矩用，注意别让销轴受反复冲击。
5. **轴向间隙 0.30 mm 是留给打印件的**（层纹、翘边）。端盖夹紧时**别把行星架盘夹死** ——
   要夹的是**齿圈**，行星架盘要能自由转。
6. **润滑**：可以用**塑料齿轮脂 / 硅脂**，薄薄一层就够，别用会溶胀 PLA 的油。
   要更顺滑可以少量涂在齿面与销轴上。
7. **方案 E / F 特有的三点**（E 是 m = 0.70、F 是 m = 0.80；都是几何层面的观察，没做过受力计算）：
   - 齿比 C/D 小（**F 小 5.9~11.1%，E 小 17.6~22.2%**，相对 m = 0.85 / 0.90 算），
     **同样的打印误差（层纹、收缩、齿面粗糙）折算成空回会更大** ——
     这是选小外径的代价，不是可以靠调参数消掉的。
   - 太阳轮 Ø5 D 孔到齿根只剩 **E 1.666 mm / F 2.260 mm**，行星轮 Ø7 孔壁 **E 2.212 mm / F 3.028 mm**
     （C 是 2.856 / 3.843）。压轴承时**别用锤砸**：加热行星轮到 60~70 °C 再压，或者先用铰刀轻修孔。
     **F 比 E 宽裕得多，这也是推荐先打 F 的原因之一。**
   - 太阳轮**轮毂 Ø10.00 比齿根粗（E 齿根 Ø8.33、F 齿根 Ø9.52）**，在齿根下面形成一圈凸台 ——
     这是有意的（Ø5 D 孔周围要留壁）。轮毂在 Z = −6.00…0，和行星轮不在同一个平面上，不干涉。
     想让它缩进齿根里，说一声我改成 Ø8.5（E）/ Ø9.7（F）重出。

8. **方案 G / H 特有的三点**（G 是 m = 0.80 的 22 : 1、H 是 m = 0.85 的 20 : 1；都只是几何观察，没做受力计算）：
   - **一级太阳轮 `04_input_sun` 的 Ø5 D 孔壁只剩 G 1.540 mm / H 1.792 mm**（F 2.260 mm，C 2.856 mm）。
     单级比要从 4.71429 提到 5.0 / 5.5，一级太阳轮只能取 12 齿，孔壁就跟着薄了 ——
     **这是 G / H 相对 F 最实质的退步**。输入扭矩大、或者要反复拆装的话，这一圈壁是薄弱点。
     插 D 轴务必先试装（第 4 节末那条对 G / H 同样适用，而且更要注意）。
   - **H 的一级重合度只有 1.204**（G 1.269，F 1.361）：12 齿小齿轮配 Ø48 齿圈，中心距变动把齿圈内齿顶削得比较浅。
     干涉为 0、能正常转，但齿与齿交替承载的平稳性不如 G / F。
   - **两级行星轮是两种零件**（G：21 齿 ×3 + 18 齿 ×3；H：18 齿 ×3 + 16 齿 ×4），H 还要多打 1 个行星轮和 1 根销轴。
     换回来的东西是：**G 的输出侧空回 18.24′ 比 F 的 18.93′ 还小一点**，齿圈也只比 F 大 1.60 mm ——
     也就是说「整数比」这个要求并没有把性能换掉多少（H 略差一点：19.22′）。

9. **方案 J 特有的三点**（J 是 m = 0.95 的 25 : 1，两级同一套齿轮；都只是几何观察，没做受力计算）：
   - **行星轮只有一种、共 6 个**，两级随便插 —— 这是 J 相对 G / H 的全部意义（G 21/18 齿两种、H 18/16 齿两种，装错就啮合不上）。
   - **齿圈 Ø54.81、行星架盘 Ø43.39**，是 E / F / G / H / J 五个里最大的一套（比 F 大 4.86 mm），
     但比 C（Ø55.44）/ D（Ø55.88）小。**端盖让位腔、热床摆放都按 Ø54.81 留**。
   - **太阳轮 Ø5 D 孔壁 2.297 mm**（F 2.260、G 一级 1.540、H 一级 1.792）—— J 虽然单级比更高、太阳轮只有 12 齿，
     但模数抬到 0.95 把孔壁补回了 F 的水平；代价落在齿圈外径上。
   - 输出侧空回 17.4′（比 F 的 18.9′ 小，比 C 16.8′ / D 15.9′ 略大）；整机 21050.99 mm³（比 F 重 3594.30 mm³，比 C / D 轻）。

10. **方案 K 特有的四点**（K 是 m = 0.95 的 16 : 1，每级 4 个行星轮、两级同一套齿轮；几何都是算出来的设计值）：
   - **每级 4 个行星轮**：两个行星架各 4 根销轴，行星轮 8 个（同一个件）。好处是每根销轴受力小
     （输出 4 N·m 时每根销轴 **64.6 N**，J 是 92.0 N）；坏处是零件多两个、行星架盘要做到 Ø43.84。
   - **齿圈 Ø55.21 是「离 Ø56 上限最近」的一版（只剩 0.79 mm）**，也是外径第三大（D Ø55.88 > C Ø55.44 > K = L Ø55.21）。
     **端盖让位腔、热床摆放都按 Ø55.21 留**，装配时也别在齿圈外面再加东西。
   - **齿顶厚 0.694 / 0.694 / 0.963 mm，是九版里最厚的** —— 0.4 喷嘴很轻松，照 F / J 的参数打即可。
     代价落在重合度上：行星-齿圈 1.301、太阳-行星 1.257（九版最低的是 L 的 1.213 / 1.136），
     转起来比 J（1.324 / 1.530）略「硬」。
   - **总比 16 : 1 比 J 的 25 : 1 小**，同样输入扭矩下输出端扭矩少一截；换回来的是空回更小（17.0′ vs 17.4′）
     和销轴受力更小。16 的额外好处是能整除 4096（4096 / 16 = 256，输出一圈正好 256 个编码器计数）。

11. **方案 L 特有的四点**（L 是 m = 0.95 的 25 : 1，每级 4 个行星轮、两级同一套齿轮 12-18-48；几何都是设计值）：
   - **齿数跟 J 完全一样**，所以空回几乎没变（单级 14.50′、两级输出侧 17.40′；J 是 14.49′ / 17.39′）。
     相对 J 真正换到的是**受力**：每根销轴 **68.6 N**（J 92.0 N）、行星轮齿根 **45.9 MPa**（J 75.5 MPa），
     三个齿顶厚也从 0.531 / 0.630 / 0.956 涨到 **0.660 / 0.806 / 1.007 mm**。
   - **装配多一个注意点**：每级的 4 个行星轮**分两种摆放相位**（差半个齿距，同一个件）——
     见第 4 节相位那段。这是 K（16 + 16 = 32 能被 4 整除）没有的事。
   - **齿圈 Ø55.21 和 K 完全相同**，离 Ø56 只剩 0.79 mm；**但它和 K 的齿数组合不同**，两版零件不通用。
   - **重合度 1.136 / 1.213 是九版里最低的**（K 是 1.257 / 1.301），转起来比 J / F 略「硬」；
     另外 **25 不整除 360（14.4）也不整除 4096（163.84）** —— 这版是按「放开这两条」选的。

12. **方案 M 特有的三点**（M 是 m = 0.95 的 25 : 1，每级 4 个行星轮、齿厚 4.00；几何与应力都是算出来的设计值）：
   - **齿厚 4.00 是这一版唯一的目的**：同为输出 4 N·m（均分到 4 个行星轮），行星轮齿根 **35.5 MPa**
     （L 齿厚 3.10 是 45.9 MPa，**降到 77 %**）、太阳轮 34.8、齿圈 14.6；每根行星销 68.6 N（与 L 相同）。
     反推（按行星轮齿根）：许用 30 MPa → 3.38 N·m、**40 MPa → 4.50 N·m**、50 MPa → 5.63 N·m。
     **这是纯齿根悬臂梁静力估算，不含齿面接触 / 疲劳 / 冲击 / 温度**；树脂件的许用值要按材料与层向自己定。
   - **代价全在轴向**：整机 27.10 → **28.90 mm**、齿圈 10.70 → **13.60 mm**。
     **旧 J / L 的端盖盖不住 M** —— 端盖按 **齿圈 −1.00 / 12.60、轮毂端面 −6.00、凸台顶 22.90** 重画。
   - **M 的齿圈 Ø55.21 与 K / L 完全相同**（离 Ø56 只剩 0.79 mm），但**齿厚 4.00 是独一份** ——
     三个方案三个目录，**零件不通用**；分不清就量齿宽（4.00 是 M）。
