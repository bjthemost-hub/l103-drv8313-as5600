# 两级行星减速机 J 版（25 : 1）

**FDM 3D 打印的两级行星减速机。总减速比 25.0000 : 1，两级行星轮是同一个零件。**

> 数字口径：本文的几何与性能数字都是**设计值 / 计算值**（建模 + 解析式 + 布尔校核）。
> 原工程**没有实机打印件，也没有实测背隙**。每处数字后面标了出处（文件名 + 章节），
> 这些文件都在本目录下；查不到的写「资料未给出」。

## 5. 装配

顺序出处：`注意事项_打印与装配.md` 第 4 节。J 用的就是 C ~ F 那套件名，行星轮 6 个。

1. 清掉行星轮内孔、齿圈内齿的毛刺。
2. 每个行星轮压一个 **Ø7 外径轴承**（6 个）。轴承厚 3 mm 时正好嵌在 3.10 深的内孔里；压不进先轻微铰孔，或用热风枪把行星轮加热到 **60 ~ 70 °C** 再压（PLA 别过热）。
3. 3 个行星轮套到 `04_carrier1_sun2` 的 **3 根销轴**上（销轴朝 −Z）。
4. `03_input_sun` 从**下方**插进这 3 个行星轮中间，让太阳轮齿与行星轮啮合。
5. 另外 3 个行星轮套到 `05_output_carrier` 的 3 根销轴上（同样朝 −Z）。
6. 齿圈立起来，**Z = −0.30 那面朝下**。
7. 一级总成从齿圈上方放入，一级行星轮进入齿圈内齿的下段。
8. 二级总成从上方放入，一边下一边轻转，让一级行星架顶上那颗二级太阳轮插进全部二级行星轮之间。
9. 盖上自画的输入端盖 / 输出端盖，把齿圈夹住。

**相位**

- J 的两级是同一套齿轮：两级行星轮相位都是 **10.0000°**，齿圈烘入 **60.0000°**，二级太阳轮烘入 **10.0000°**；6 个行星轮是同一个件，随便插（`图纸与交付说明.md` 第 6 节）。
- 相位已经做进零件，按 STEP 方位装，不用自己找角度；齿圈不能反装（同上）。

**销轴与间隙**

- 销轴 **Ø4.06 × 3.40**，只是穿在行星轮 **Ø7.00** 内孔里，**径向间隙 1.47 mm**；真正承力 / 定心靠压进去的 Ø7 轴承（`图纸与交付说明.md` 第 8 节、`注意事项_打印与装配.md` 第 7.2 条）。
- 行星轮上下各留 **0.30 mm** 轴向间隙，是留给打印件层纹 / 翘边的（`图纸与交付说明.md` 第 4 节）。
- **开打前先用卡尺量手上 Ø7 轴承的内孔**：销轴按 **Ø4.06** 出。若内孔是 Ø4.00（资料举的例子是 MR74ZZ 4×7×2.5 那类），Ø4.06 是过盈 0.06 mm，多半插不进；若是 Ø3.0 / 3.6（683ZZ 那类）则完全插不进，得改销轴（`图纸与交付说明.md` 第 8 节）。

**润滑**：塑料齿轮脂 / 硅脂，薄薄一层就够，别用会溶胀 PLA 的油；要更顺滑可少量涂在齿面与销轴上（`注意事项_打印与装配.md` 第 7.6 条）。

**背隙**

- 设计值：单级 **14.49′**，两级**输出侧 17.39′**，输入侧 **86.94′ = 1.45°**；齿侧间隙 0.0601 / 0.0599 mm；齿厚减薄 thin = 0.030 mm/齿（每侧 0.015）（`图纸与交付说明.md` 第 3 / 7 / 14.3 节）。
- **打印后一定更大**，大多少没有数据（`图纸与交付说明.md` 第 7 节）。
- 量法：输入端 D 轴夹死、齿圈固定，输出凸台装 50 mm 摆臂 + 百分表，正反各推一次读差；**1 mm 端点位移 = 1.146° = 68.75′**（`注意事项_打印与装配.md` 第 6 节）。

## 6. 强度与转速边界

| 问题 | 结论 | 出处 |
|---|---|---|
| 输出 4 N·m 能不能挺住 | **挺不住**。行星轮齿根约 **75.5 MPa**（太阳轮 63.4、齿圈 28.9），比「PLA 打印件敢长期吃」的 15 ~ 25 MPa 高 3 ~ 5 倍 | `工作报告_2026-09-30_J版_4Nm与500rpm强度估算.md` 第 0 / 2 节 |
| 那能长期用多少 | **约 1 N·m 上下**：许用 15 / 20 / 25 MPa 对应 **0.79 / 1.06 / 1.32 N·m** | 同上 第 5 节 |
| 输入 500 rpm 有救吗 | **救不回来**。500 rpm 输入 = 20 rpm 输出（25:1），**静应力与转速无关**；变的是循环次数与发热 | 同上 第 4 节 |
| 500 rpm 具体改变什么 | 一级啮合频率 **100 Hz**，100 小时 **3600 万次**；节点滑移 **0.304 m/s** | 同上 第 4 节 |
| 加宽齿宽能到多少 | b = 4.2 / 4.4 / 4.6 / 5.0 mm 对应 **1.08 ~ 3.42 N·m**（看敢用 15 ~ 40 MPa 哪个许用值）；**5 mm 也到不了 4 N·m** | `工作报告_2026-09-30_J版_齿宽加宽_输出扭矩上限.md` 第 0 / 3 节 |

**这些数是怎么来的**（同一份文档里写明的）：

- 齿廓不是查表，是把 J 自己的 `02_planet_gear.stl` / `03_input_sun.stl` / `01_ring_gear.stl` 在齿带中点 z = 1.55 切片取实际轮廓，按悬臂梁 `σ = 6·F·g / (b·t²)` 扫出来的；临界截面 g* = 1.945 mm、t* = 1.515 mm（`工作报告_2026-09-30_J版_4Nm与500rpm强度估算.md` 第 2 节）。
- 载荷路径：T = 4 N·m、3 个行星轮、a = 14.49185 mm，得到每个啮合点切向力 46.00 N、每根行星销 92.0 N（同上 第 1 节）。
- 用标准 Lewis 口径算同一件事约 50 MPa，按 J 实际齿廓是 75.5 MPa；**真值大概在 50 ~ 75 之间，报告全程取 75.5（保守端）**（同上 第 2 / 6 节）。

**四条必须一起看的边界**（同上 第 3 / 5 / 6 节、加宽报告第 7 节）：

- **3 个行星轮均分载荷是理想情况**。没有均载销，齿厚公差、中心距误差、销的挠度都在，实际可能 2 个甚至 1 个轮在扛 —— **应力再乘 1.5 ~ 3 倍**。
- **许用应力 15 ~ 25 MPa 是取的假设值，不是实测**：PLA 丝料 datasheet 拉伸强度 40 ~ 60 MPa 量级（没指定牌子、没实测）再打 1/2 ~ 1/3。
- **E = 3000 MPa、ν = 0.35 也是假设值**（PLA 量级，不是实测），只影响接触应力与销的挠度，不影响齿根那一列。
- 全部是**静态齿根悬臂梁估算**：**没有有限元、没有台架加载、没有疲劳数据、没有 PV / 发热许用值**。

同工程另两版的估算对照（都是计算值，不是实测）：同为 25 : 1，J（每级 3 个行星轮、齿宽 3.10）行星轮齿根 75.5 MPa，L（每级 4 个行星轮、齿宽 3.10）45.9 MPa（`注意事项_打印与装配.md` 第 7.11 条）。另外，3 → 4 个行星轮的估算给出「扭矩上限 +33%、轴向一点不长、相邻行星轮齿顶净间隙 +1.561 mm」（`工作报告_2026-09-30_J版_齿宽加宽_输出扭矩上限.md` 第 6.1 节）。

## 7. 已知限制与未验证

1. **没有打印件、没有实测**：所有几何 / 性能数字都是设计值 / 计算值；没打印、没测背隙、没做台架加载、没有有限元（`图纸与交付说明.md` 开头、`工作报告_2026-09-30_J版_4Nm与500rpm强度估算.md` 第 8 节）。
2. **背隙只有设计值** 14.49′ / 17.39′；打印后实际值未知，量法见第 5 节（`图纸与交付说明.md` 第 7 节）。
3. **输入轮「只有齿轮」版没有轴承位**，传扭矩只能过盈 / 紧定螺钉 / 胶；A/B/C 的孔与轴压装、传扭能力**没实测**（`J_ratio25/说明_J输入轮_只有齿轮.md` 第 四 / 六 节）。
4. **销轴 Ø4.06 与轴承内孔的配合未验证**：Ø7 轴承的内孔到底多少，资料里也是「要用卡尺量」（`图纸与交付说明.md` 第 8 节、`注意事项_打印与装配.md` 第 8 节）。
5. **端盖 / 外壳没做**：J 只给到齿圈、齿轮与两个行星架；输入端盖、输出端盖、电机 / 联轴器接口都要自己画（`图纸与交付说明.md` 第 5 节）。
6. **STL 不是测量基准**：三角化容差 A/B/C 取 0.006、装配体取 0.02，是给预览 / 打印用的（`J_ratio25/工作报告_2026-10-13_J版输入轮_只有齿轮.md` 第 三 节）。
7. **`00_assembly` 只是几何装配，不含配合公差**（`J_ratio25/说明_J输入轮_只有齿轮.md` 第 六 节）。
8. **25 不整除 360（14.4）也不整除 4096（163.84）**：如果上层要按整圈 / 编码器计数取整，J 的 25 : 1 不是整数圈（`注意事项_打印与装配.md` 第 7.11 条）。
9. **跨方案零件不通用**：J 的 m = 0.95、齿圈 48 齿、架盘 Ø43.39，和 C ~ H 的任何一件都配不上；J 与 K 都是 48 齿、外径只差 0.40 mm，但内齿顶不同（J Ø44.640 / K Ø45.091），行星轮也不通用（`图纸与交付说明.md` 第 14.6 节、`注意事项_打印与装配.md` 第 4 节）。
10. **输入轮 v2（Ø16 轴承位）本仓库未附**：需要就自己改，参数见第 2.2 节。
11. **齿轮-only 输入轮没有专门的打印 / 摆放参数** —— 资料未给出。
